{{ _('Thundermail') }} {{ _('Protocols') }} {{ _('Supports IMAP4rev1/rev2 over TLS, authenticated SMTP submission, and JMAP for Mail (RFC 8621) over HTTPS. JMAP batches operations and supports push updates, reducing round trips on high-latency connections.') }}
{{ _('Inbox model') }} {{ _('Aliases and custom-domain addresses map to one mailbox rather than separate accounts. Use server-side Sieve rules or client filters to sort messages by recipient address.') }}
{{ _('Spam detection') }} {{ _('Powered by Stalwart; classifies inbound mail server-side using rules, reputation signals, and statistical analysis. Thundermail tunes the scoring to reduce false positives.') }}
{{ _('Webmail') }} {{ _('Open-source (MPL 2.0) JMAP web client with a browser-local SQLite cache backed by IndexedDB. Early alpha became available in July 2026.') }}
{{ _('SMTP Mail Relay') }} {{ _('Authenticated SMTP submission is available on port 465 with implicit TLS and port 587 with STARTTLS. App passwords let clients, devices, and services send without using the main account password.') }}
{{ _('Server-side Filtering') }} {{ _('Supports ManageSieve (RFC 5804) for uploading and activating server-side Sieve scripts from a compatible client. Rules execute at delivery time, even while your mail clients are offline.') }}
{{ _('Unlimited calendars') }} {{ _('No plan-level limit on calendar count. Synchronize via CalDAV (RFC 4791) or JMAP for Calendars, whose event model is JSCalendar; the JMAP calendar extension is currently an IETF Internet-Draft.') }}
{{ _('Unlimited contacts') }} {{ _('No plan-level limit on contact count. Synchronize via CardDAV (RFC 6352) or JMAP for Contacts (RFC 9610), whose ContactCard objects use the JSContact format (RFC 9553).') }}
{{ _('Addresses & domains') }} {{ _('Custom domains') }} {{ _('Bring up to three domains. Setup is guided, but DNS remains customer-managed: activation requires MX plus three hosted-DKIM CNAMEs; the wizard also supplies SPF, DMARC, service-discovery SRV, MTA-STS, and TLS-RPT records.') }}
{{ _('Aliases') }} {{ _('Aliases are additional delivery addresses on the same mailbox, not separate accounts. A matching @tb.pro address is provisioned automatically with your primary @thundermail.com address; custom-domain addresses are managed separately.') }}
{{ _('Catch-all aliases and + addressing') }} {{ _('Create one catch-all per verified custom domain to receive mail for otherwise undefined local parts. Catch-all is not available on the shared @thundermail.com or @tb.pro domains.') }}
{{ _('Appointment') }} {{ _('External calendar connection') }} {{ _('Connect a CalDAV account by server URL and credentials. Appointment performs service discovery, reads busy time, and writes confirmed bookings back to the source calendar; it is scheduling integration, not full calendar replication.') }}
{{ _('Availability rules') }} {{ _('Recurring weekly rules support multiple time ranges per weekday and a selected time zone. One-off date overrides and blackout dates are not currently supported.') }}
{{ _('Booking window') }} {{ _('Choose immediate, 12-hour, or 1-5-day minimum notice and a 1-4-week booking horizon. Bounds use elapsed clock time, not business-day calculations.') }}
{{ _('Meeting duration') }} {{ _('Each schedule uses one fixed duration: 15, 30, 45, 60, 75, or 90 minutes. Slots are generated back-to-back after conflict filtering.') }}
{{ _('Unified view') }} {{ _('The week view overlays connected-calendar events, pending booking requests, and computed free slots. Manage your scheduled bookings without accidentally editing your calendar items.') }}
{{ _('Booking management') }} {{ _('Owners can approve or decline requests, enable automatic confirmation, and cancel bookings. Rescheduling and modification are not yet supported.') }}
{{ _('Booking link') }} {{ _('Public booking pages require no visitor account and use a customizable, rotatable apt.mt slug; rotating it invalidates the previous URL.') }}
{{ _('Video meetings') }} {{ _('Zoom connects through OAuth; each confirmed booking can create a distinct Zoom meeting and join URL. A static meeting URL is also supported; Google Meet integration is currently being developed.') }}
{{ _('Storage') }} {{ _('Mail storage') }} {{ _('The Early Bird plan includes 30 GB per inbox; internally this is a 30 GiB Stalwart quota, with usage reported by the mail server.') }}
{{ _('Send storage') }} {{ _('The Early Bird plan includes 60 GB of Send storage (60,000,000,000 bytes), with a 20 GB maximum per file.') }}
{{ _('Bundled services') }} {{ _('Appointment') }} {{ _('Appointment is included with the subscription, providing availability sharing and self-service scheduling to reduce booking coordination by email.') }}
{{ _('Send') }} {{ _('Send is included for end-to-end encrypted file sharing. Before upload, every file is encrypted with a unique 256-bit AES-GCM key; that key is wrapped with a per-folder 256-bit AES-KW key, and neither is stored in plaintext on the server.') }}
{{ _('Privacy & security') }} {{ _('Data hosting') }} {{ _('All of your Thundermail data, including messages, calendars, contacts, Appointment bookings, and Send files, is stored on infrastructure located in Germany.') }}
{{ _('App passwords') }} {{ _('Managed from the account dashboard. OAuth2-capable clients use Thunderbird Accounts sign-in. Legacy clients share one replaceable app password, stored only as an Argon2 hash; replacing it invalidates every client using it, and plaintext cannot be recovered.') }}
{{ _('2-Factor Authentication') }} {{ _('Protect your account with authenticator-app TOTP (RFC 6238) and one-time recovery codes. SMS and email recovery are not supported.') }}
{{ _('Access & setup') }} {{ _('Thunderbird desktop') }} {{ _('Beginning with Thunderbird 153 ESR, Account Hub provides one-click OAuth2 setup. The integration ships as a bundled system extension, so no separate add-on install is required; mail still uses IMAP and SMTP over TLS.') }}
{{ _('Mobile apps') }} {{ _('Thunderbird for Android connects over IMAP and SMTP with TLS and OAuth2. JMAP support on Android is not yet shipped.') }}
{{ _('Webmail') }} {{ _('Access webmail from the account dashboard using Thunderbird Accounts/OIDC; no client configuration or app password is required.') }}
{{ _('Third-party clients') }} {{ _('Use IMAP on port 993 plus SMTP on port 465 over TLS, or JMAP Mail/Submission over HTTPS on port 443. OAuth2 is preferred; app passwords support legacy clients. POP is not offered.') }}
{{ _('Onboarding') }} {{ _('The dashboard QR code imports TLS, OAuth2, server, username, and identity settings into Thunderbird for Android; it embeds no password or token. Thunderbird 153+ uses Account Hub for one-click desktop setup; custom-domain DNS remains guided and manual.') }}
